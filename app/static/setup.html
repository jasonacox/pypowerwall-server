Set up PyPowerwall Server

New installations can be configured from the browser at /setup. The wizard guides you through gateway access, integrations, and server settings, then saves a persistent configuration. All supported gateway modes, multi-gateway and hybrid setups are available; existing YAML and environment-variable setups remain supported.

Setup API access The setup API uses PW_CONTROL_SECRET as its admin token. If PW_CONTROL_SECRET is not set, use the temporary setup token printed in the server startup log. Search for Setup wizard access token. The token is only valid until the server restarts.
